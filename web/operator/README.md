# web-operator

Портал оператора (V-001): React + Vite + Mantine (ТЗ §3), клиент API — из контракта
[`contracts/openapi`](../../contracts/openapi/openapi.yaml). Дорожка: **Платформа**. ТЗ — [`doc/STAGE1_SPEC.md`](../../doc/STAGE1_SPEC.md), §4.1, §7.1.

## Что есть

- вход, восстановление пароля, новый пароль по ссылке, принятие приглашения (V-002);
- свой профиль: имя, язык, пароль, выход со всех устройств;
- пользователи оператора: список с фильтрами, приглашение, роль и язык, блокировка, удаление (V-003);
- End User: приглашение к клиенту, клиенты, блокировка, удаление (§7.5) — выбор клиента заработает с API клиентов (4.3);
- журнал аудита с фильтрами (V-005), настройки платформы с уровнем значения и сбросом к унаследованному (V-006);
- создание арендатора — для SIG Administrator;
- меню разделов по ролям (V-001); разделы, экраны которых появятся со своей частью API, показывают заглушку.

Меню и прямые ссылки скрывают то, что роли не разрешено, по `x-roles` контракта (`src/api/roles.json`). Это только
удобство: права проверяет сервер на каждый запрос (§7.1).

## Запуск

```
pnpm gen       # типы API и права из contracts/openapi → src/api (результат в git)
pnpm dev       # http://localhost:5173, /api проксируется на API_URL (по умолчанию http://localhost:3000)
pnpm test      # проверка, что src/api совпадает с контрактом, и тесты интерфейса (Vitest)
pnpm build
```

Для разработки по http сервис `api` запускается с `COOKIE_SECURE=false`.

## Как устроено

- `src/api/client.ts` — `openapi-fetch` с типами из `schema.d.ts`; cookie сессии ставит сервер, `X-CSRF-Token` из ответа
  входа добавляется к изменяющим запросам. Токен хранится в `localStorage`, чтобы пережить перезагрузку страницы (он
  привязан к сессии HMAC-ом и без cookie бесполезен).
- `src/auth/session.tsx` — профиль (`GET /me`), вход, выход; 401 на запрос при живой сессии — переход на вход.
- `src/i18n/en.ts` — тексты интерфейса (английские — наши, P-01d); переводы — тем же набором ключей.

## Решения, которых нет в ТЗ (на согласование)

1. **Язык портала оператора** — пока английский; переводы LV, RU, ET, LT подключаются тем же набором ключей, как в портале End User.
2. **CSRF-токен в `localStorage`** — иначе после перезагрузки страницы пришлось бы входить заново.
3. **Разделы без API** (дашборд, устройства, карта, клиенты, алерты, отчёты, eSIM) видны по ролям, но показывают заглушку
   до своих частей API.
